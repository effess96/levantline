# levantline

Small tools and templates for cafes, restaurants and local businesses. Made in Amman, Jordan.

## What is here
- `tools/qr-menu/` free QR code tool (runs in the browser, nothing uploaded)
- `demo-landing/`, `demo-menu/`, `demo-bot/` live demos
- `kit-landing-bot-v1/` listing texts and gallery images for the landing template and bot gigs
- `img/` shared images
- `index.html` home page (v1.1): product cards, demo links, light and dark

## Rules
- Work on branches, merge by pull request. Never push to main.
- No private numbers, keys or personal data in this repo.
- Full rules for agents and sessions: `CLAUDE.md`.
